## Phase 2: Branch Architecture (Backend)

### 2.1 — Prisma Schema — `server/prisma/schema.prisma`

**Add Branch model**:
```prisma
model Branch {
  id           String   @id @default(uuid())
  name         String
  address      String
  latitude     Float
  longitude    Float
  phone        String?
  workingHours Json?
  isActive     Boolean  @default(true)
  createdAt    DateTime @default(now())
  updatedAt    DateTime @updatedAt

  products     Product[]
  orders       Order[]

  @@map("branches")
}
```

**Add to Product model**:
```prisma
  branchId String?
  branch   Branch? @relation(fields: [branchId], references: [id])
```

**Add to Order model**:
```prisma
  branchId String
  branch   Branch @relation(fields: [branchId], references: [id])
```

### 2.2 — Migration

## Phase 4: Audit Fixes

### 4.1 — Remove mock data dependency — `src/store/useStore.js`
- Remove all `import ... from '../data/mockData'`
- Remove mock fallback on API failure → show error toast/message instead
- All data fetches go through `src/lib/api.js`
- For initial load: if API fails, show "Server bilan bog'lanib bo'lmadi" error

### 4.2 — Token storage security
- **Backend** (`server/src/middleware/auth.js`): Keep httpOnly cookie setting, REMOVE token from JSON response body
- **Frontend** (`src/lib/api.js`): Remove localStorage read for tokens; rely on `credentials: 'include'` for cookie-based auth
- **Frontend** (`src/store/useStore.js`): Remove `localStorage.setItem('accessToken'/'refreshToken')` calls; remove `localStorage.removeItem` on logout
- Add automatic 401 handling: on 401, call refresh endpoint, retry request
